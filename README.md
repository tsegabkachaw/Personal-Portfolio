# Tsegab Kachaw — Developer Portfolio

A minimal-dark personal portfolio website with an AI-powered assistant.

## 🎯 Overview

A responsive portfolio website showcasing my profile, projects, skills, and contact details. Features an AI-powered chat assistant that answers visitor questions using a curated knowledge base.

## 🏗️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, vanilla JavaScript |
| Backend | Serverless function (TBD) |
| AI | Claude API |
| Knowledge Base | Markdown files |
| Version Control | Git & GitHub |

## 📁 Project Structure

```
├── index.html              # Main portfolio page
├── css/
│   └── style.css           # All styles (design system + layout)
├── js/
│   └── main.js             # Interactions, navigation, chat widget
├── assets/
│   ├── images/             # Profile photo, project screenshots

│   ├── faq.md

```

## 🎨 Design

**Concept:** Minimal Dark — clean, spacious, Apple-level professional aesthetic.

- Near-monochrome dark palette
- Generous whitespace
- Typography-driven hierarchy
- Subtle hover interactions

## 🚀 Features

- Responsive design (360px to 1920px)
- Dark minimal aesthetic
- AI chat assistant with curated knowledge base
- Downloadable CV
- Smooth animations and transitions
